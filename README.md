# NebulaSchool-Android
Nebula School Android - Kotlin, Jetpack Compose

## Sito CV (GitHub Pages)
È stato aggiunto un sito statico in `/docs/index.html` con stile minimalista e colori vivaci per:
- caricare il PDF del CV europeo
- caricare il PDF della lettera di presentazione
- visualizzare l'anteprima immediata dei due file

### Pubblicazione online
1. Vai su **Settings > Pages** del repository.
2. In **Build and deployment**, seleziona **Source: GitHub Actions**.
3. Effettua push su `main` (o avvia manualmente il workflow **Deploy static site to Pages**).
4. Il sito sarà disponibile all'URL:
   `https://mammt09876567890.github.io/NebulaSchool-Android/`
